# infra — local ERPNext + India Compliance (Phase 0)

Runs the base system (Frappe/ERPNext `version-16` + India Compliance `version-16`) in Docker on
the dev laptop, using the official [frappe_docker](https://github.com/frappe/frappe_docker)
cloned into `vendor/frappe_docker` (reference only, gitignored — see `docs/dev-boundaries.md`).

| File | Committed? | Purpose |
|---|---|---|
| `apps.json` | yes | Apps baked into the image (ERPNext, India Compliance) |
| `erp.sh` | yes | `build` / `up` / `site` / `down` / `logs` helper |
| `.env.local` | **no** | DB + Administrator passwords, image tag, port |
| `compose.local.yaml` | **no** | Generated by `erp.sh up` (contains secrets) |

## First run

```bash
# -c core.autocrlf=false is required on Windows: CRLF shell scripts break the container
# entrypoint ("exec /usr/local/bin/entrypoint.sh: no such file or directory").
git clone -c core.autocrlf=false --depth 1 https://github.com/frappe/frappe_docker vendor/frappe_docker
# create infra/.env.local with: DB_PASSWORD, ADMIN_PASSWORD, CUSTOM_IMAGE=merchant-erp,
# CUSTOM_TAG=16, PULL_POLICY=never, HTTP_PUBLISH_PORT=8080, FRAPPE_SITE_NAME_HEADER=merchant.localhost
infra/erp.sh build   # ~15–30 min
infra/erp.sh up      # wait ~10 s for the configurator to exit
infra/erp.sh site    # creates merchant.localhost with erpnext + india_compliance
```

Then open <http://localhost:8080> and log in as `Administrator`.

Requires Docker Desktop (WSL2 backend) running, with ≥ 4 GB memory for Docker.
